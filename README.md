# 镜序 · 短故事分镜助手

帮助首次制作 AI 剧情短视频的新手，把短故事整理成可修改的分镜参考方案。

演示：https://liulcdt.github.io/storyframe-demo/

## 能力与边界

- 九镜头编辑、排序、计划时长、本地保存、预览。
- 真实导出 Markdown 分镜方案和按当前顺序排列的九宫格 PNG。
- 套圈镜头支持预制红色项圈版本的对比、采用、恢复。
- 顶栏演示菜单可模拟下一次生成失败，旧内容保留并可重试。
- **没有连接真实 AI 模型**。任意故事输入不会触发真实生成；当前只有小狗去游乐场样例。
- 自由编辑会将参考图标记待更新，预制修正不代表其他文本修改已应用。
- 数据仅保存在当前浏览器，不跨设备同步。原图片存在项圈不一致等问题，需人工判断。

## 开发

Node.js 20.19+，执行 `npm ci`、`npm run dev`；`npm run build` 进行类型检查和构建。

GitHub Pages 使用 `docs/` 的静态构建。修改后重新构建并同步到 docs。不要向公开仓库放入密钥或个人录音。

## 来源

原九宫格由用户提供，九张切片从用户授权复用的 LiuLCDT/phanthymovie-demos 仓库复制。自动工作流只读参考 sunnygirl-0106/fastapp；本项目重新实现独立产品界面，没有修改原仓库或 PRD。

红色项圈版本使用 OpenAI imagegen 对原套圈图片做局部编辑。图像除项圈外仍有细微变化，界面通过人工对比与恢复保留用户选择。
