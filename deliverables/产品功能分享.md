# 我喜欢的功能：GitHub Pages 分享原型

我使用 GitHub Pages 发布过 PhanthyMovie 的画布打组、宫格切分等交互 Demo。这次准备笔试，我也选择沿用它，让评审直接打开链接、点击体验。

它解决的问题是：原型即使在自己电脑上运行正常，也需要被别人方便地体验。把本地文件发给别人，往往还要解释怎么打开；单发截图又无法表达完整交互。

我最喜欢的是把本地原型变成一个可访问链接。对方不必搭建开发环境，我也可以把讨论落到具体操作上。这个机制缩短了从作品制作到他人体验的距离，使分享成为创作流程自然的一步。这与创作工具降低表达和分享门槛的方向相通。

如果只能改一个地方，我希望增加一个更直观的发布检查页，把当前版本、发布状态和匿名访问检查集中呈现，减少对“评审看到的是否是最新版”的不确定感。
