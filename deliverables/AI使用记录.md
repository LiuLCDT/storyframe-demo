# 镜序｜AI 使用记录

## 使用工具与作用

- Codex：协助解读笔试要求，比较复用方向，整理范围，编写 React / TypeScript / Vite 界面与导出逻辑，运行浏览器验收，准备说明文档和录屏。
- OpenAI imagegen：基于用户提供的套圈镜头，生成红色项圈版本。运行于制作阶段，网页没有接入模型。
- GitHub Pages：托管静态交互原型，不是 AI 生成服务。

## 我做出的选择

我提出复用既有成果，要求符合题意、贴近小影并关联 PhanthyMovie 经验；我选择将完整自动流缩减为“短故事到可修改分镜”，提供小狗九宫格，并确认九镜头方案。产品文案与具体实现由 AI 辅助形成，不能把生成代码说成我手写，也不把旧项目整体能力说成个人贡献。

## AI 输出的问题与处理

1. 初步路线包含完整资产与视频生成链路，超过剩余时间：缩减为分镜计划和参考图，取消真实视频生成。
2. 原素材第 5 格已是夕阳，后面又回到白天：将摩天轮移至烟花前，按故事时间顺序重新排列。
3. 原素材项圈颜色跨镜头不一致：将套圈镜头作为局部修正示例，而非声称所有图片已一致。
4. imagegen 将蓝色项圈改成红色，但线条、细节和画面比例仍出现变化：提供前后对比、用户采用和恢复，不宣称逐像素只改项圈。
5. 旧切分代码部分路径绑定小猫素材：新工程直接绑定九张小狗切片。
6. 前端初稿依赖外部字体，可能拖慢加载：删除外部字体请求，使用本机字体。
7. 初次浏览器检查发现输入框缺乏稳定的无障碍名称：补充明确标签并重新验证。

## 关键图像编辑提示词

“Change ONLY the blue collar around the golden puppy's neck to a clearly red collar. Preserve the puppy identity, face, fur, pose, ring, ducks, stall, all lines, paper texture, framing and aspect ratio. Do not change anything else.”

实际输出并未完全满足“其他内容不变”，因此保留人工检查步骤。

## 原型真实性边界

生成与重试是定时模拟，当前只展示固定样例。文字编辑、排序、本地保存、Markdown 与 PNG 下载是真实操作。任意新故事或提示词不会生成相应图片，界面明确提示，不以随机占位图假装模型结果。没有完成用户访谈或模型效果实验，不编造效率提升指标。
