# 镜序｜2—3 分钟演示

0:00—0:20：介绍目标用户与预制原型边界，点击“使用示例”。
0:20—0:35：生成九镜头，说明从白天游玩到夕阳、烟花的顺序。
0:35—0:55：选择镜头，修改旁白和计划时长，展示自动保存。
0:55—1:10：前移、后移一个镜头，展示顺序可控。
1:10—1:35：选择“套圈小挑战”，开启模拟失败，生成后保留旧图，点击重试。
1:35—1:55：对比蓝色和红色项圈，采用新版，再展示恢复原图。
1:55—2:15：预览分镜，说明不是生成视频。
2:15—2:35：导出 Markdown 和九宫格 PNG，展示可继续编辑。

核心讲法：先让新手看清故事如何变成画面，再把修改缩小到一幕。当前验证的是操作流程，不是模型效果。
